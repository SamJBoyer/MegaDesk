Executive is the executive floor of my softare factory. It is a sophisitcated GUI that allows for 
ideation and observing agent execution. 


I'm a very visual person and I prefer to diagram and draw pictures, use whiteboards, etc. when writing 
documentation. My software development pipeline usually goes ideation (creating the idea, defining the features, chosing the tool stack, etc.) then prototyping with AI, then refining and refactoring. 

I was doing all my documentation in Lucid Chart and prefered making huge sprawling diagrams with the
entire project visualized at once. I was planning on writting a backend that used the Lucid MCP to 
connect my documententation to my backend, but sadly the lucid MCP is trash trash trash and all 
the work around are locked behind enterprise tier which I'm not gonna pay for. 

So, we get here. This project is essentially a combination of my idea for a GUI-canvas that supports 
my development GUIS with a canvas that supports documentation (like lucidchart). 

Ideation and metadata engineering. 

Lucid MCP is bad because it chunks unreliably. This means that objecst that are closed to eachother or 
visually repated appear very far in the metadata, especially when chunked. This sucks and making it so 
visual language can't be easily distilled into valuable context, which is like 80% of the point of 
documentation-first approaches in agentic setups. Soo this project will be like lucid chart but BETTER 
because it will have special metadata engineering features so groups of ideas can easily be converted into 
PDR requests, prompts, tickets, etc. etc. etc.
